# Backend: ANOMS-Originals-Store

This clean storefront consumes:

Anoms-Hub/ANOMS-Originals-Store/
- products/ -> Terrain/Sky/Structures/etc
- mockups/ -> product visuals
- listings/ -> titles/descriptions
- pricing/ -> 10 AC = $1
- integrations/ -> PayPal/Stripe/CashApp
- automation/ -> order sync

To sync new products: update seed-products.mjs in ANOMS-Originals-Store, then copy product JSON to this repo's client if needed.

Everything earns Anom Coin: +12 AC, +8 AC, +15 AC etc visible on cards.
